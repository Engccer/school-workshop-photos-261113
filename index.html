대담 중 사진 보여주기

  1. 대화에 나온 키워드를 누르면 해당 사진이 바로 나타납니다.
  2. 같은 묶음의 다른 사진은 아래의 제목 버튼이나 이전·다음 사진으로 고릅니다.
  3. 사진을 누르면 크게 볼 수 있습니다. 수첩은 확대 후 스크롤하며 읽을 수 있습니다.

프로젝터와 노트북을 따로 사용할 때

컴퓨터의 화면 설정을 ‘확장’으로 바꾼 뒤 ‘청중 화면 열기’를 누르세요. 새 창을 프로젝터 쪽으로 옮겨 전체 화면으로 전환하면, 이 창에서 고른 사진만 청중에게 보입니다. 두 창은 같은 브라우저에서 열어 두세요.

화면 하나를 함께 볼 때

키워드를 고른 뒤 ‘사진만 보기’를 누르세요. Esc 또는 ‘조작 화면으로’로 돌아올 수 있습니다.

키보드

Alt + 1~5: 키워드 선택 · Alt + ←/→: 묶음 안 이동 · Alt + 0: 대담 표지 · Esc: 확대 닫기 또는 조작 화면으로
