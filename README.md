# 대담 사진

[사진 화면 열기](https://engccer.github.io/school-workshop-photos-261113/?v=4)

설치 전, 수첩 메모, 설치 후의 세 묶음으로 원본 사진 15장을 보여 주는 대담 자료다. 좌우 화살표로 아홉 장면을 순서대로 넘긴다. 사진을 누르면 크게 열리고, 수첩은 읽기 좋은 폭으로 펼쳐진다. 사진이 표시되면 짧은 확인음이 울린다.

스크린 리더에서는 묶음·이전·다음 버튼, 현재 장면 헤딩, 사진별 제목·이미지 설명·확대 버튼 순서로 탐색한다. 확대를 닫으면 원래 버튼으로 돌아온다.

사진의 권리는 원권리자에게 있다. 효과음은 ElevenLabs로 생성한 0.48초 음원이며 `assets/photo-cue.mp3`와 `sound.js`의 음원 바이트는 동일하다. 폴더 전체를 보관하면 인터넷 없이 `index.html`을 열어 실행할 수 있다.
