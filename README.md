# 함께 일하는 학교의 이야기: 대담 사진

2026년 11월 13일 학교관리자 워크숍의 장애인교원·관리자 사례 대담 사진 자료다.

## 사용 방법

1. `index.html`을 브라우저에서 연다.
2. 대화에 나온 키워드 버튼을 누른다. 출근길, 교실 환경, 교장 선생님 수첩, 점자블록, 점자 안내의 다섯 묶음이다.
3. 묶음 안의 제목 버튼이나 이전·다음 사진으로 이동한다.
4. 사진을 누르면 크게 볼 수 있다. 수첩은 ‘크게 확대’ 후 스크롤한다.

프로젝터와 노트북을 확장 화면으로 연결한 경우 ‘청중 화면 열기’로 새 창을 열어 프로젝터로 옮긴다. 같은 브라우저에서 두 창을 열어 두면 사진 선택과 확대가 동기화된다. 한 화면만 쓰는 경우 ‘사진만 보기’를 사용하고 Esc로 돌아온다.

단축키: Alt + 1~5로 묶음 선택, Alt + 방향키로 묶음 안 이동, Alt + 0으로 대담 표지.

인터넷 없이도 폴더 전체를 내려받아 `index.html`을 열 수 있다. HTML 파일과 `assets` 폴더는 함께 보관한다. 외부 글꼴, 분석 도구, 외부 라이브러리를 사용하지 않는다.

## 사진과 문구

신명중학교 편의지원 전 현장 사진, 2022년 4월 출근길 사진, 2022년 7월 편의시설 설치 후 사진, 정구헌 교장 선생님의 업무 수첩 사진을 사용한다. 사진 원본의 내용과 비율을 유지한다. 모든 사진에 장면을 설명하는 대체 텍스트를 제공한다.

수첩은 당시 기록으로 제시한다. 수첩에 적힌 제도와 예산 금액을 현재 지원 기준으로 안내하는 자료는 아니다.

사진의 권리는 원권리자에게 있다. 사진의 재사용 허락을 별도로 부여하지 않는다.
