# 대담 사진

[사진 화면 열기](https://engccer.github.io/school-workshop-photos-261113/)

출근길, 교실, 수첩, 점자블록, 점자 안내의 다섯 키워드로 사진 15장을 보여 주는 대담 자료다. 사진 선택과 확대에 짧은 확인음을 제공한다.

사진은 제공받은 원본이며 권리는 원권리자에게 있다. 효과음은 ElevenLabs로 생성한 0.48초의 짧은 타격음이다. 생성 음원은 `assets/photo-cue.mp3`, 오프라인 재생을 위한 동일 음원 내장본은 `sound.js`다.

인터넷 없이도 폴더의 `index.html`을 열어 실행할 수 있다. 사진과 음원, 코드 파일은 함께 보관한다.
